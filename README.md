1) null এবং undefined এর পার্থক্য-

undefined মানে হলো কোনো ভেরিয়েবল declare করা হয়েছে কিন্তু কোনো মান দেওয়া হয়নি।
null মানে ইচ্ছাকৃতভাবে খালি বোঝানো হয়।

2) map() এবং forEach() এর পার্থক্য-

map() সাধারণত ব্যবহার করা হয় যখন নতুন array তৈরি করতে হয়।
forEach() ব্যবহার করা হয় শুধু loop করার জন্য।

3) == এবং === এর পার্থক্য-

== শুধু value compare করে 
=== value এবং type দুইটাই compare করে

4) async/await এর গুরুত্ব-

async/await ব্যবহার করলে asynchronous code সহজভাবে লেখা যায়।
API fetch করার সময় কোড clean ও readable হয়।
Promise chaining এড়ানো যায়।

5) Scope কি?

Global Scope: পুরো ফাইলে access করা যায়।
Function Scope: শুধু function এর ভিতরে।
Block Scope: {} এর ভিতরে কাজ করে।
